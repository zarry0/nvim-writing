# Plantillas DOCX

Los proyectos Markdown pueden incluir un archivo `reference.docx` en su raíz.
Pandoc usará sus estilos, márgenes, encabezados y pies de página al ejecutar
`:WriteExport docx`.

Este repositorio no incluye un DOCX binario genérico: se recomienda preparar uno
por clase de documento y copiarlo al proyecto que lo necesite.
